# Микроинвест Архив — ELTECH

Независим инструмент на ELTECH за архивиране и възстановяване в отделно копие на SQL Server бази и Access файлове. Това не е официалният продукт Microinvest Архив Pro.

## Изтегляне

Изтеглете ZIP от [последното издание](https://github.com/bilyanaeltech/Microinvest-Archive/releases/latest), разархивирайте и стартирайте BackUpClientEltech.exe. Windows 10/11 x64; .NET runtime е включен.

## Активиране и обновяване

В „Лицензиране“ копирайте серийния номер и го предайте на ELTECH за издаване на код за този компютър. От „Актуализации“ → „Провери онлайн“ се проверява наличната версия. Програмата проверява цифровия подпис и SHA-256 на актуализацията преди инсталиране.

Това хранилище съдържа клиентски издания. Частни ключове, инструментът за издаване на лицензи, клиентски лицензи, настройки, пароли и архиви не се публикуват.
